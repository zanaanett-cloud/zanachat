# Zana Chat Android

Aplikasi Android Zana Chat untuk Android 10 (API 29) ke atas.

Domain:
https://chat.zananet.my.id/

Fitur:
- Android 10+
- Responsive
- PWA
- Kamera
- Mikrofon
- Notifikasi
- Getar
- GitHub Actions
- Ikon Zana Chat

Build:
1. Upload seluruh isi folder ini ke GitHub.
2. Gunakan branch main.
3. Buka Actions.
4. Pilih Build Zana Chat APK.
5. Run workflow.
6. Download artifact zana-chat-debug-apk.

Catatan:
APK ini merupakan wrapper untuk web Zana Chat.
Alamat web: https://chat.zananet.my.id/
